# Таро «Космический мистицизм»

Проект таро-приложения. Два внешне независимых направления на одном ядре:

- **(A) «Таролог»** — платный Telegram-бот с раскладами и ИИ-толкованиями;
- **(B) Сайт + бот «Уведомитель»** — бесплатные пуши «расклад готов», возвратный трафик на сайт.

## Содержимое

- `TZ-tarot-app.md` — техническое задание (актуальная версия).
- `research-*.md` — исследования: расклады, технологии, паттерн Help, конкуренты, цены.
- `content/meanings-*.json` — толкования всех 78 карт, черновик на русском.
  Формат каждой карты: суть → психология → практика (работа / отношения / личное)
  → перевёрнутая позиция → ключевые слова.
- Колода: 78 карт, 1280×1920, WebP (будет добавлена отдельно).
